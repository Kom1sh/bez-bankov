# Финансовая свобода без банков: возможно ли это в 2026 году

Доклад на 3 минуты для занятия по банковским инструментам. Пять слайдов.
Тезис: полностью без банков в 2026 году почти невозможно. Наличными просто проходят два
платежа из восьми привычных, ещё три — только в отделении, остальные идут через банк.

Живая версия: https://kom1sh.github.io/bez-bankov/ — закрыта от индексации.
PDF рядом: `bez-bankov.pdf`. Текст выступления: `SPEECH.md`.

## Данные

Доля безнала, банкоматы, офисы, СБП, наличные в обращении, QR и биометрия — Банк России
(обзоры НПС, статистика, денежные агрегаты на 1.09.2026). Цифровой рубль — закон 248-ФЗ,
Банк России, Интерфакс 23.09.2026. Как платить без карты — ТК ст. 136, НК ст. 45, ГК ст. 140,
КоАП ст. 14.8, Почта России, АМПП, РБК и iXBT (Ozon, 28.09.2026). Платёжные привычки —
опрос Банка России и НАФИ за 2025 год, SuperJob (сентябрь 2026).
Полная таблица фактов с источниками и уверенностью — `SOURCES-research.md`.

## Как править

```
python3 src/make_slides.py && python3 src/build.py && python3 src/qa.py
```

`src/make_slides.py` — содержание и цифры, `src/deck.tpl.html` — оформление, `DESIGN.md` —
палитра и правила (донор токенов Wise). `src/qa.py` обязателен перед показом.
Управление в показе: стрелки, `O` — обзор слайдов, `F` — полный экран.
